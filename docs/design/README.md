# SceneBook Design System

This folder is the canonical SceneBook design system.

## Source Of Truth

The original HTML source of truth is `docs/design/source/Pasted-code.html`.
The extracted token files are in `docs/design/tokens`.
The brand pack should guide the full dark-first UI/UX revamp.

Designers and engineers must not invent new colors, radii, shadows, typography, or motion values.

## Phase Guardrail

"Do not modify app UI or global tokens in this ingestion phase. This phase only installs the design source of truth."
